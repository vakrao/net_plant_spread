Directory Description
--------------
Here, we list two different scripts where we use the windscape library to plot the relationship between wind travel time and the connection between different nodes. The first script, `hub_windmap.R`, plots the heatmap posted in the Supplmentary Materials, in Figure S8. 
We plot a hub node, and its different connections. 

The other script `wind_connect.R` plots the relationship between the wind distance and the wind travel time, in Figure S9. 
Within this script, we also generate the CCDF for three different wind distances (0-10 km, 11-20 km, and 20+ km) shown in Figure S10.
The notebooks used to visualize the figures in the manuscript are in the `manuscript_notebooks` folder. 

Scripts
---------
- **hub_windmap.R** plots the heatmap shown in Figure S8
- **wind_connect.R** plots the scatter plot shown in Figure S9 and the CCDF in Figure S10
